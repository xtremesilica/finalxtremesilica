# Final Xtreme Silica Project Control

Focused GitHub Pages interface derived from the Xtreme Silica dashboard.

## Visible controls

- Home
- Marketing
- Assign Project
- Task Progress

The legacy Home and Marketing dashboard content is intentionally hidden. The Assign Project workflow and Task Progress dashboard retain their existing API integrations with `https://automation.sionsemi.com`.

## Hosting

Publish from the `main` branch root using GitHub Pages.
